## Overview

SecureBox is a cross-platform mobile application built with React Native and Android (Gradle) that integrates with external financial REST APIs while prioritizing security and resilience. The client implements hardware-backed encryption (AES-256-GCM and Kyber-768), intelligent retry mechanisms, and LLM-driven automated diagnostic test suites that verify zero memory leaks and unhandled exceptions under stress conditions.

## Architecture

The application follows a layered architecture: a React Native UI layer communicates through a typed REST API client that implements caching, exponential backoff, and hardware-backed cryptographic operations. A separate LLM-driven diagnostic agent runs automated boundary tests and stress scenarios independently of the main app.

## Key Features

- **Hardware-Backed Encryption**: AES-256-GCM for symmetric data encryption and Kyber-768 (post-quantum) for key encapsulation, backed by device hardware security modules where available.
- **Resilient API Client**: Client-side response caching, exponential backoff, and automatic retry mechanisms for robust connectivity against unreliable network conditions.
- **LLM-Driven Diagnostics**: Agentic scripts powered by LLM APIs automatically run diagnostic and boundary test suites, verifying zero memory leaks and unhandled exceptions under stress.
- **Cross-Platform**: Runs on both iOS (React Native) and Android (Gradle build) with a unified codebase.
- **Financial API Integration**: Secure integration with external financial REST APIs, including input validation and response schema enforcement.

## Technologies Used

- **React Native**: Cross-platform mobile UI framework targeting iOS and Android.
- **Android & Gradle**: Android-specific build system and native module integration.
- **AES-256-GCM**: Symmetric encryption for data at rest and in transit.
- **Kyber-768**: Post-quantum key encapsulation for future-proof key exchange.
- **REST APIs**: Integration with external financial data APIs with typed client contracts.
- **LLM API Automation**: AI-driven agentic scripts for automated boundary and stress testing.
- **Linux/UNIX**: Development and CI environment for scripting and automated test pipelines.

## Challenges and Learnings

The primary challenge was integrating hardware-backed key storage (Android Keystore) with the Kyber-768 post-quantum KEM, since the Keystore natively supports classical algorithms only. A hybrid approach was used — the classical key pair lives in the Keystore, and Kyber operates in-process, with the final derived key protected by the Keystore-backed key. The LLM-driven diagnostic framework required careful prompt design to generate meaningful boundary conditions rather than trivial happy-path tests.

## Outcome

The LLM-driven diagnostic suite confirmed zero memory leaks and zero unhandled exceptions under stress testing, reducing manual debugging effort by 70%. Hardware-backed AES-256-GCM encryption was verified to add negligible latency overhead on target Android devices, with the hybrid Kyber-768 integration successfully protecting key material from classical cryptanalysis.
