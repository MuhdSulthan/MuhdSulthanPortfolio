## Overview

During my internship at Kerala Police Academy (June – July 2024), I designed and deployed a comprehensive pfSense firewall and network security solution to automate traffic isolation, eliminate unmonitored ingress routes, and engineer forensic tooling for network anomaly investigation. The project combined firewall engineering, Python scripting, and packet-level forensic analysis.

## Key Features

- **Automated Subnet Routing**: Custom Python audit scripts automated network routing and traffic isolation across 4 subnets on the pfSense firewall, eliminating unmonitored ingress routes and optimizing network throughput.
- **Forensic Packet Analysis**: Investigated network anomalies using Wireshark packet capture across 25+ digital endpoints, achieving 100% audit compliance.
- **Python Forensic Microservice**: Engineered an object-oriented Python forensic microservice to reconstruct network event timelines, cutting turnaround time by 30%.
- **Intrusion Detection**: Integrated Suricata IDS for comprehensive threat detection and prevention across the network perimeter.
- **Network Segmentation**: Implemented DMZ configuration, VLAN segmentation, and VPN with multi-factor authentication for authorized remote access.

## Technologies Used

- **pfSense**: Open-source firewall and router platform for enterprise-grade network security.
- **Python**: OOP-based audit scripts and forensic microservice for routing automation and timeline reconstruction.
- **Suricata**: Network intrusion detection and prevention system for real-time threat monitoring.
- **Wireshark**: Network protocol analyzer for deep packet inspection and forensic analysis.
- **TCP/IP & Subnetting**: Network routing design and subnet isolation across 4 segments.
- **VirtualBox**: Virtualization platform for the isolated lab environment.

## Challenges and Learnings

The primary challenge was designing Python audit scripts that could accurately detect unmonitored ingress routes without triggering false positives — requiring careful analysis of routing tables and firewall state. Building the forensic microservice to reconstruct network event timelines from packet captures taught me how to handle temporal data gaps and correlate events across multiple sources efficiently.

## Outcome

The deployment achieved 100% audit compliance across 25+ digital endpoints. The Python forensic microservice reduced timeline reconstruction turnaround by 30%. The automated subnet routing scripts eliminated all unmonitored ingress routes, with comprehensive logging providing full forensic visibility for the Kerala Police Academy's network security operations.
